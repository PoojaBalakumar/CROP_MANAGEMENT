Project Overview
This project presents a Reinforcement Learning (RL)-based decision support system for long-term agricultural crop planning under uncertainty. The goal is to help farmers optimise land allocation across multiple crops over a multi-year horizon while ensuring financial stability and avoiding bankruptcy.
Unlike traditional crop planning models, this project incorporates both **annual crops** and **multi-year crops (tree crops)**, introducing realistic challenges such as delayed revenue and long-term investment decisions.

---

Objectives

- Develop a Virtual Farm simulation environment
- Model stochastic agricultural conditions (price, yield, cost)
- Implement and compare multiple RL algorithms:
  - Proximal Policy Optimization (PPO)
  - Deep Q-Network (DQN)
  - Q-Learning
  - SARSA
- Evaluate performance across 1,000 simulation runs
- Analyse risk, stability, and long-term profitability

---

 Key Features

- Multi-year crop modelling (3-year maturity for trees)
- Stochastic environment (weather, yield variability)
- Financial constraints (costs, savings, bankruptcy)
- Performance comparison across RL algorithms
- Visualisation of results and trends
